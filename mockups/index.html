CineApp — Mockups de pantallas

Maquetas SVG de las 8 pantallas principales. Cada archivo en la carpeta mockups/ se puede importar directamente en Figma (arrastra el .svg al lienzo). Los textos son editables en Figma.

1. Home Tab

Hero carousel + secciones horizontales con "Ver más" + tab bar

2. Detalle de película Stack

Trailer, guardar, dónde verlo, sinopsis, reparto

3. Detalle de serie Stack

Mismo layout + selector de temporadas

4. Buscar Tab

Input con debounce + chips Películas/Series/Personas + grid

5. Perfil de actor Stack

Foto, bio, métricas y filmografía navegable

6. Mi Lista Tab

Grid de favoritos persistidos con opción de quitar

7. Lista completa ("Ver más") Stack

Grid de 2 columnas + paginación infinita

8. Carga (Skeleton) Estado

Esqueletos animados mientras cargan las queries

Paleta: fondo #09090B · superficie #18181B · acento #8B5CF6 · texto #FAFAFA · texto atenuado #A1A1AA.
Importar a Figma: abre Figma → nueva página → arrastra los archivos .svg al lienzo (o File → Import). Cada SVG entra como un frame editable.
